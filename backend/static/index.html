How a file is processed

  1. 1

    Load the file

    Drop an Excel, CSV or PDF. A Particulars column and one or two amount columns are enough. Add Vendors, RelatedParties or Segments sheets to switch on the extra checks. Scanned PDFs can be read with OCR on the server.

  2. 2

    Match each line

    Every line is mapped to the audit procedure for that kind of item and to the provisions that apply: Companies Act sections, SEBI rules, Ind AS and the Standards on Auditing.

  3. 3

    Rank by priority

    Size, change from the prior period and risk combine into a score. High, Medium and Low show where to look first. A rank is a starting point for review, not a finding.

  4. 4

    Review and export

    Open any line to see its procedure, its standard and the check that raised it. Save the project, then export a Word or PDF report.

What it covers

Balance sheet and P&L
Line-by-line mapping, a priority score, and flags that name the check that raised them.
Vendors
Duplicate payment patterns and a Benford's law test on the leading digits of vendor amounts.
Related parties
Vendor records cross-checked against the related-party sheet for relationships that were not disclosed.
Segments
An accountability index for each segment, including whether an owner has been assigned.
SA 610
The internal audit function scored question by question, so an external auditor can see how far it can be relied on.
Section 138
Whether the internal audit requirement appears to apply, tested against the size thresholds using the figures loaded.
Other statements
Cash flow, changes in equity, sales and gross profit, corporate governance, litigation and tax planning each have their own tab.

It suggests. It does not conclude.

  • Answers from the data only. The Assistant uses the figures and law map loaded on the page, and names the line or provision behind each answer.
  • No verdicts. A flag is a prompt for an audit procedure. Nothing AIMsquare produces says that a person committed fraud.
  • A record that cannot be quietly edited. Sign-ins, saves, exports and Assistant exchanges are written to a hash-chained audit log. Change one entry and verification fails.
  • You still verify. Check every legal reference before relying on it. AIMsquare does not replace professional judgement.

Frequently asked questions

Is my file uploaded anywhere?

Excel and CSV files are read in your browser. A PDF goes to the AIMsquare server only if you sign in and choose server reading for scanned pages. There it is processed in memory and not stored.

Do I need an account?

You can load a file and review the analysis without one. Sign in to save projects, export Word and PDF reports, use the Assistant and verify the audit log.

What does a project save?

The extracted figures and your SA 610 answers. The original files are not kept.

Does it tell me whether fraud has happened?

No. It ranks lines, raises flags and names the procedure to perform. A flag is a question to ask, not an accusation.
